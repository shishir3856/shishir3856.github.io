# Shahriar Kabir Shishir | Research Portfolio

This repository contains a static portfolio website for Shahriar Kabir Shishir, designed for academic, research, and governance-focused professional positioning.

## Structure

- `index.html` – homepage
- `about.html` – professional profile
- `research-projects.html` – research portfolio
- `publications.html` – publications listing
- `experience.html` – experience timeline
- `training.html` – training and certificates
- `engagement.html` – conferences, leadership, and civic engagement
- `skills.html` – methods and skills
- `cv.html` – CV preview and download
- `contact.html` – contact information
- `assets/css/style.css` – design system and layout
- `assets/js/main.js` – navigation behavior and small enhancements
- `assets/images/` – local visual assets and placeholders
- `assets/documents/` – downloadable CV placeholder

## Local preview

From the repository root:

```bash
python -m http.server 8000
```

Then open:

- http://localhost:8000/

## Notes

- The site uses placeholder assets where verified material is not yet available.
- Content is intentionally conservative and avoids invented publications, roles, or affiliations.
- The CV file is stored as a placeholder PDF in `assets/documents/` until an official version is provided.
